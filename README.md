# 🌱 AgroStation — Умная агростанция

Общий репозиторий нашего учебного проекта. Здесь собираем всё в одном месте: прошивку, 3D-модели корпуса и будущего бота, чтобы ничего не терялось в переписке.

## 📊 Текущий статус (на чем мы сейчас)

* **Прошивка (`/firmware`):** основной код на ESP32 готов, сейчас разбираемся со схемой подключения, чтобы всё стабильно заработало в сборе.
* **Корпус (`/case`):** в активной разработке — допиливаем и загружаем актуальные 3D-модели.
* **Бот (`/bot`):** пока в планах, скоро начнем.

---

## 📁 Где что лежит

* **`/firmware`** — код прошивки для ESP32 (PlatformIO) и распиновка.
* **`/case`** — модели корпуса (`.stl`, `.step`), чертежи и рендеры.
* **`/bot`** — папка под Telegram-бота.

---

## 🚀 Инструкция для команды: как пользоваться репозиторием

Не обязательно знать сложные консольные команды — всё можно делать прямо через браузер за пару кликов.

### 1. Как скачать актуальную версию проекта себе на ПК
* **Через браузер (проще всего):** на этой странице сверху нажми зеленую кнопку **`<> Code`** → **`Download ZIP`**.
* **Через терминал (если установлен Git):**
  ```bash
  git clone https://github.com/awernet192/agrostation-project.git
  ```
  *(Чтобы потом подтянуть свежие изменения от других ребят, в папке проекта выполни `git pull`).*

### 2. Как добавить свои новые файлы (например, модели корпуса или код бота)
1. Зайди в нужную папку прямо здесь на сайте (например, кликни на **`case`** или **`bot`**).
2. Справа сверху нажми **`Add file`** → **`Upload files`**.
3. Перетащи свои файлы в окно браузера.
4. Внизу в поле **Commit changes** коротко напиши, что добавил (например: *«Добавил крышку корпуса v2»*) и нажми зеленую кнопку **`Commit changes`**.

### 3. Как обновить уже существующий файл
Если ты поправил свою модель или файл:
1. Просто закинь его через **`Add file` -> `Upload files`** в ту же папку с **точно таким же именем** — GitHub сам обновит файл до новой версии (а старую сохранит в истории на всякий случай).
2. Либо через терминал на ПК:
   ```bash
   git add .
   git commit -m "Обновил модель корпуса"
   git push
   ```

> 💡 **Важно:** Если папка на GitHub пока пустая (как `/bot`), её не видно в списке. Чтобы она появилась, при создании файла через **`Add file` -> `Create new file`** просто напиши в названии `bot/README.md` — папка создастся автоматически.
